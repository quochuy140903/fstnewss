🌐 Cào Chuẩn 100% Video & Caption Qua Chrome Đang Bật VPN Mỹ (Surfshark)

Vì các Fanpage Mỹ (SNL, Movie...) chặn IP Việt Nam và chỉ mở khi đi qua VPN trên trình duyệt Chrome của bạn, công cụ này lấy trực tiếp video gốc ngay trong Chrome đang bật VPN — đảm bảo đúng 100% video của từng link Reels, không bao giờ tải nhầm video khác!

⚡ Cách 1: Chạy Trực Tiếp Ngay Lập Tức (Chỉ 5 Giây — Không Cần Cài Đặt)
  1. Bấm nút màu xanh "📋 Copy Mã Cào Chuẩn & Mở Tab Facebook" bên dưới (Mã đã chứa sẵn toàn bộ danh sách link Reels của bạn).
  2. Tại tab Facebook vừa mở trên Chrome (đang bật VPN Surfshark), nhấn phím F12 ➔ Chọn tab Console (Bảng điều khiển).
  3. Nhấn Ctrl + V rồi bấm Enter (Nếu Chrome lần đầu hỏi allow pasting thì gõ chữ allow pasting rồi Enter, sau đó Ctrl+V lại).
  4. Chrome sẽ tự động quét đúng từng ID Reels qua VPN Mỹ, gửi toàn bộ Link Đích Mẫu + Caption + Tải Đúng Video Gốc (.mp4) về thẳng bảng Quản Lý của Tool!
🧩 Cách 2 (Tùy chọn): Cài Tiện Ích Cầu Nối Chrome VPN Tự Động 100%

Nếu bạn muốn lần sau chỉ cần bấm nút trên Web Tool là tự động cào ngầm qua VPN Chrome mà không cần bấm F12: Mở chrome://extensions ➔ Bật Chế độ nhà phát triển (Developer mode) ở góc phải trên ➔ Bấm Tải tiện ích đã giải nén (Load unpacked) ➔ Chọn thư mục: D:\CV\Tool\chrome_vpn_extension

📗 Hướng Dẫn Kết Nối Tự Động Điền Vào File Google Sheet (Chỉ 30 Giây)

1. Mở file Google Sheet của bạn ➔ Trên thanh menu chọn Tiện ích mở rộng (Extensions) ➔ Apps Script (Hoặc mở trang script.google.com ➔ Dự án mới).

2. Xóa đoạn mã mặc định và dán đoạn mã dưới đây vào, sau đó bấm biểu tượng Lưu (💾):

function doPost(e) {
  var data = JSON.parse(e.postData.contents);
  var ss = data.sheet_url ? SpreadsheetApp.openByUrl(data.sheet_url) : SpreadsheetApp.getActiveSpreadsheet();
  var sheet = ss.getActiveSheet();
  var rows = data.rows || [];
  sheet.clearContents();
  sheet.appendRow(["STT", "Link Reels & Fanpage", "Fanpage Mẫu", "Tiêu Đề (Title)", "Link Đích Mẫu (Cào Bài)", "Link Web Của Tôi (Link Chính)", "Caption AI Mới", "Caption Hoàn Chỉnh", "File Video Mẫu", "Trạng Thái"]);
  for (var i = 0; i < rows.length; i++) {
    var r = rows[i];
    sheet.appendRow([i + 1, r.source_url || "", r.uploader || "", r.title || "", r.cta_link || "", r.my_web_link || "", r.new_title || "", r.formatted_caption || "", r.video_filename || "", r.process_status || ""]);
  }
  return ContentService.createTextOutput(JSON.stringify({status: "ok", count: rows.length})).setMimeType(ContentService.MimeType.JSON);
}
